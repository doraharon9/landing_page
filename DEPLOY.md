# SocialBite Platform

Live restaurant discovery platform powered by social media recommendations.

## Live Demo

Visit the live platform: [Coming soon after deployment]

## Features

- Natural language search for restaurants
- Interactive map with restaurant locations
- Real social media posts and mentions
- Smart search algorithm

## Tech Stack

- React 18
- Express.js
- Leaflet Maps
- Node.js

## Local Development

```bash
npm install
npm run dev
```

## Deployment

This app is deployed on Render.
